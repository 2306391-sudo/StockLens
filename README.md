# StockLens

StockLens is a full-stack stock market analysis application that provides stock information, market insights, watchlists, portfolio tracking, news, and AI-assisted explanations.

## Features

- 📊 Stock market dashboard
- 📈 Stock price and candlestick charts
- 🔎 Stock search
- ⭐ Watchlist management
- 💼 Portfolio tracking
- 📰 Market and stock-related news
- 🤖 AI-assisted stock explanations
- 🌍 Geographical/market risk information
- 🔔 Price alert functionality
- 🔐 User authentication

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express
- REST APIs
- WebSocket support

### Other Technologies
- JavaScript / TypeScript
- npm
- Vercel
